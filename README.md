# MIAO · 产品与 AI

一个可以改成自己作品集的交互式静态网站。湖面是导航的一部分，访客可以点开水面的光点查看内容，也可以浏览个人介绍、调节昼夜或播放音乐。[体验线上网站](https://miaaavvv.github.io/miao_index/)

## 可以用它做什么

| 用途 | 可以怎么改 |
| --- | --- |
| **个人主页或求职作品集** | 把介绍与教育栏换成自己的背景和经历，把水面入口换成自己的项目或代表作。 |
| **课程、毕业设计或创作展览** | 让每个水面光点对应一件作品，在详情里用文字和图片介绍过程与结果。 |
| **多个项目的展示站** | 把光点作为各项目的入口，详情用来介绍功能、展示界面或说明设计取舍。 |

这些用途都可以部署成静态网页。公开站点无需访客登录，也无需运行数据库或应用服务器。

## 复用前先换这些内容

| 要改什么 | 在哪里改 |
| --- | --- |
| 网站名称、加载页、分享标题和链接 | [`index.html`](index.html) 和 [`entry-experience.js`](_v/src/entry-experience.js) |
| 自我介绍、展示条目及详情 | [`portfolio-content.js`](_v/src/portfolio-content.js) |
| 简体中文、繁體中文和英文的界面文案 | [`local-i18n.js`](_v/src/local-i18n.js) |
| 图片、字体、渲染素材和音频 | [`_p/`](_p/) 和 [`_media/`](_media/) |
| 导航、阅读面板和手机布局 | [`local-ui.css`](_v/local-ui.css) |

修改作品集内容时同步更新三种语言。发布前换成你有权公开使用的文字、图片与音频，并把分享链接和封面地址改成自己的部署地址。

## 自带哪些体验

- **交互湖面与昼夜。** 点击或拖动水面产生涟漪，可切换景观和视角，调整时间与光线。底部播放器提供切歌、进度和音量控制。
- **适配手机和键盘。** 窄屏使用底部导航和可滚动的详情面板。支持键盘进入和退出项目，也兼顾系统的「减少动态效果」设置。
- **完整首帧和内容回退。** 加载页在湖面、岸线和倒影绘制完成后退出；湖景先用轻量纹理呈现，再在后台提升细节。浏览器不支持 WebGL 或出现加载故障时，页面提供可阅读的内容摘要。
- **链接分享。** 页面提供通用分享元信息和微信内打开系统浏览器的指引。微信定制分享需要配置签名服务。 [微信分享配置](WECHAT_SHARING.md)

## 本地运行

使用 Node.js 20 或更新版本，项目无需安装依赖。在仓库根目录运行以下命令。

```sh
npm run dev
```

在浏览器打开本地预览。端口被占用时，可设置 `PORT` 后重启。Windows PowerShell 中可运行 `$env:PORT = "5174"`，再运行 `npm run dev`。 [本地预览](http://127.0.0.1:5173/)

发布前运行 `npm run check`，检查素材与引用路径、响应式布局、渲染预算、加载回退和分享配置。

## 部署到 GitHub Pages

1. 在你的仓库打开 **Settings → Pages → Build and deployment**，将 **Source** 设为 **GitHub Actions**。
2. 将部署工作流里的 `--base=/miao_index/` 换成 `/<你的仓库名>/`。如果站点部署在域名根路径，则使用 `--base=/`。 [部署工作流](.github/workflows/pages.yml)
3. 将改动推送到 `main`。工作流会自动检查、构建和发布，也可在 **Actions** 页面手动运行。

如需在本地生成部署产物，请执行以下命令。按你的部署路径替换 `--base`，生成的文件位于 `.local/pages-dist/`。

```sh
npm run build:pages -- --base=/miao_index/
```
