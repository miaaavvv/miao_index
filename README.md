# MIAO · 个人网页

在线访问：https://miaaavvv.github.io/miao_index/

参考网站：https://oscardumlao.com/ 。2026-11-03 保存的本地交互版本，保留原站的字体、布局、WebGL 水面渲染、景观、介绍面板、时间调节、场景轮换和音乐播放器。

## 启动

需要 Node.js 20 或更高版本，无需安装依赖。

```sh
npm run dev
```

打开 http://127.0.0.1:5173 。服务固定监听 `127.0.0.1`，仅供本机访问。

如果端口已占用：`PORT=5174 npm run dev`。

## 交互

- 点击或按住拖动水面，产生涟漪和环境音。
- 左上角显示 MIAO，右上角可切换简体中文、繁體中文和 English。
- 右侧导航包含场景、项目、个人介绍、教育经历；鼠标悬停或键盘聚焦时展开图标与名称。
- 场景面板集中提供场景轮换、三种景观、纯水面/远景视角、时光转换、微风、涟漪、光线及恢复默认效果。
- Change scene 轮换景观与视角；切换视角时会重新加载渲染器，并保留场景面板的打开状态。
- 点击左侧时间读数或场景面板里的“时光转换”，打开原站位于画面中央的竖向时间刻度条；上下拖动调节时间，按 Escape 或点击外部关闭。
- 个人介绍依据用户简历更新，公开姓名仅为 MIAO，包含水彩剪影、简介、工作/实习、教育及技能；不提供电话和邮箱。
- 点击“项目”后，AI 交互式混音、Agent 内容生产、睡眠监测优化、Deeptracker 四个案例以光点、编号和细涟漪分布在湖面；悬停显示一句简介，并触发真实水面涟漪。
- 点击坐标查看完整案例：桌面右侧展开详情，手机使用底部详情面板，均支持前后项目切换。方向键、Home / End 可切换坐标焦点；Escape 先关闭详情，再退出项目模式。
- 坐标根据窗口尺寸和水面位置调整，详情打开时避让阅读区域；时间、介绍、场景等入口会退出项目模式。
- 教育经历提供独立入口，并在个人介绍中保留相同的学历信息。简体、繁体和英文内容同步。
- 底部居中为播放器，包含前后曲、播放/暂停和音量；点击音量图标调节主音量或静音，点击曲名查看波形与进度。
- 专注计时及独立设置入口已移除。
- 背景右键菜单仅提供场景操作，不提供联系方式。
- 播放音乐需要用户先操作页面，符合浏览器自动播放规则。

## 语言默认规则

- 首次访问通过本地 `/api/region` 查询网络所在国家/地区代码：CN 使用简体；TW、HK、MO 使用繁体；其他使用英文。
- 地区查询只读取 Cloudflare 连接信息中的国家/地区代码，不记录或向页面返回 IP 和其他诊断字段；查询结果缓存在服务器内存中。网络代理会影响识别到的地区。
- 查询超时或离线时，依次回退浏览器的明确地区和时区。语言字典均在本地，查询失败不影响页面使用。
- 手动切换后，偏好保存在当前浏览器，后续访问优先使用手动选择，不再自动覆盖。
- 本地验证可以使用 `MIAO_REGION=TW PORT=5174 npm run dev` 指定地区；不设置时正常查询网络地区。

## 性能策略

- 动态背景的输出像素比上限为 1.25（低性能设备 1.1），并设总像素预算；掉帧时同时缩小水面与最终输出，避免只降低中间水面而仍以高分辨率合成。
- 云层使用较小的离屏图像，分四块更新并在完成后整体交换，避免一次更新整张体积云造成长帧。景观照片与正文不降采样。
- 普通水面交互目标为 60fps；阅读项目、介绍、教育和其他面板时，背景目标为 30fps，并暂停装饰坐标环。关闭面板后恢复 60fps 目标。实际帧率随设备和浏览器而变。
- 面板改用高不透明度背景，移除叠在持续变化水面上的实时背景模糊。文字与按钮仍按浏览器正常清晰度绘制。
- 页面切到后台后，沿用渲染器原有的暂停机制。前后台切换、时间与场景控制保持可用。

## 移动端适配（2026-11-18）

- 小于 1000px 时使用底部四项导航，播放器在导航上方；场景、项目详情、个人介绍和教育采用可滚动的大面板，阅读时收起背景播放器。
- 导航、语言、关闭、项目切换、播放器与滑杆等主要触控区域至少 44px，布局避让设备安全区域。短横屏浏览项目时收起播放器，保留案例关闭、前后切换和底部导航。
- 图集支持横向浏览，设计图大图支持单指左右滑动切图；多指操作不触发切图。正文保持独立纵向滚动，浏览器可处理阅读区域的缩放手势。
- 时间与波形对话框增加三语关闭按钮；时间的全屏触摸调节排除导航、语言和关闭按钮，避免误捕获控件操作。水面仍支持触摸点击、按住与拖动。
- `npm run check` 覆盖 17 种布局尺寸，包含 320px 小屏与手机横屏，核对坐标不重叠、不侵入播放器和导航区域。浏览器以窄屏视口验证布局、滚动与主要控件；实际手机 Safari / Chrome 的触摸、缩放和刘海安全区域仍需真机复核。
- 当前服务继续仅监听 `127.0.0.1`，本项适配未改变本机开发范围。
